# 키·인증서·자격증명 목록

**값은 절대 이 파일에 적지 않는다 — 위치 참조만** (원칙 1·2, D12). `access:` 필드의
`keys.md#<이름>` 앵커는 아래 표의 "이름" 컬럼과 일치해야 한다(audit가 검사).

- `kind`: `ssh-key | tls-cert | api-token | cloud | account | password` 중 하나(audit가 검증).
- `principal`: 주체(계정명·사용자명). 계정·비밀번호에 필요, 키·토큰은 생략 가능(`-`).
- `fingerprint`: 종류별 선택 — ssh 키·tls 인증서엔 유용, 비밀번호엔 무의미(`-`).
- `위치 참조`: 값이 있는 곳(외부 `~/.ssh/...`·`op://...`·`vault://...` 또는 하네스 내부
  `secrets/....age`). 반드시 채운다(audit가 누락을 검사).
- `usage`: 안전한 참조 실행 방법. 비밀번호는 **argv 금지**(ps/history 유출) —
  `sops exec-env <파일> '<명령>'` · `op run -- <명령>` · stdin/FD만 쓴다.
- `생성일` / `만료·로테이션`: 두 컬럼으로 분리한다. audit의 만료 경고는 **마지막 컬럼만**
  본다(생성일을 만료일로 오인하지 않는다). 만료·로테이션 예정이 없으면 `-`.
