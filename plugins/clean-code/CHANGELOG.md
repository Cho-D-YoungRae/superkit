# Changelog

이 플러그인의 버전은 [Semantic Versioning](https://semver.org/lang/ko/)을 따른다. 1.0.0 전에는
마이너 버전이 호환되지 않는 변경을 담을 수 있다.

## 0.2.0 — 2026-10-17

리뷰를 읽기 전용 리뷰어 에이전트에 맡긴다. 레퍼런스를 읽는 비용이 메인 대화 밖에서 들고, 리뷰 형식이 일정해진다.

### Added

- `review` 스킬: 대상(경로·커밋 범위·현재 브랜치 변경·전체)을 정하고 `clean-code-reviewer`를 띄워 결과를 심각도 순 리포트로 정리한다. 경로를 주면 변경이 아니라 그 파일 전체를 본다. 파일이 많으면 리뷰어를 나눠 동시에 띄운다. 리뷰어가 단 근거와 `(원서 밖)` 표시는 그대로 옮긴다.
- `clean-code-reviewer` 에이전트(sonnet, 읽기 전용): 17장 목차 표로 냄새 후보를 고르고 해당 항목만 읽는다. 지적마다 17장 휴리스틱 코드(없으면 챕터 절)를 근거로 달고, 원서 밖 의견은 따로 적고 원서 밖 보충에서 온 제안에는 `(원서 밖)`을 붙이며, 짧은 범위의 짧은 이름 같은 오탐을 내지 않는다.

### Changed

- `apply`: 리뷰 트리거를 description에서 빼고, 검토만 원하는 요청은 `review`로 넘긴다. 고치는 중에 냄새를 확인할 때만 17장 목차 표를 직접 본다.

## 0.1.0 — 2026-10-17

처음 공개한다.

### Added

- `apply` 스킬: 코드를 쓰거나 리팩터링·리뷰할 때 작업에 맞는 챕터 레퍼런스만 골라 읽고 적용한다. 프로젝트 지침·린터·다른 컨벤션 스킬과 부딪치면 그쪽을 따른다.
- 레퍼런스 `skills/apply/references/`: 전체 목차와 한 줄 요약을 담은 `index.md`, 코드 작성에 쓰이는 챕터별 요약(1~14, 16, 17장, 13장은 부록 A 포함). 서문·15장·부록 B/C·에필로그는 `index.md`에만 둔다.
- `scripts/verbatim_check.py`: 레퍼런스가 원서 문장을 연속으로 옮겨 오지 않았는지 대조한다(원서 텍스트는 저장소에 두지 않는다).
- `tests/test_references.py`: 스킬 앞머리, index와 챕터 파일의 링크, 챕터 파일 형식을 검사한다.
