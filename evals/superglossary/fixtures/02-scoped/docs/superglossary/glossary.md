# 용어 사전

| 한글 | 영문 | 축약 | 금지 | 설명 |
| --- | --- | --- | --- | --- |
| 식별자 | identifier | id | | 고유한 식별 값 |
| 일시 | datetime | at | | 날짜와 시간 |
| 부여 | grant | | issue | 토큰 권한을 부여할 때 grant를 사용. issue 금지는 토큰 권한 부여 의미에만 적용. 외부 계약 필드 issuedAt은 예외로 유지 |
| 발행 | issue | | | 채권을 발행한다. 토큰 권한 부여와 별개인 금융 개념 |
| 채권 | bond | | | 발행하는 채무증권 |
| 토큰 | token | | | 인증 권한을 담은 토큰 |
